# CSS Art-Emoji
This assignment is meant for you to solidify and show off your skills and knowledge for: positioning, transitions, animations, and CSS art.

## Due Date: 28/10

## Submissions:  
Create a live website with your IDE and submit a link to that site on Jupiter.

## Expectations:  
Use this link as a starting point: [codeHS CSS Art](https://codehs.com/tutorial/mattarnold/css-art)  
You are to make a piece or art using HTML and a lot of CSS. It can be an emoji like you see in the link above, or it can be any piece of art you want. Be creative and have fun with this!
- I am expecting to see a variety of shapes used.
- Transitions
- Animations
- Hover techniques

Your page should be broken down into 4 sections:
### Section 1:
Showing off your Best CSS art
### Section 2:
Showing off transitions, hovers, etc.  
### Section 3:
Showing off animations
### Section 4:
A clean professional footer. *The footer should contain your name.*
